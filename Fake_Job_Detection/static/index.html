About JOBCIPHER AI

Learn how this system detects fraudulent job postings using AI and NLP.

What is JOBCIPHER AI?

JOBCIPHER AI is an AI-powered fake job posting detection system that uses Natural Language Processing (NLP) and Machine Learning to identify potentially fraudulent job listings. It analyzes the text content of job postings — including titles, descriptions, requirements, and benefits — and classifies them as either genuine or potentially fraudulent.

Designed for job seekers, researchers, and HR professionals, JOBCIPHER AI provides an instant, data-driven second opinion on any job posting — helping protect people from scams, identity theft, and financial fraud commonly disguised as legitimate job opportunities.

Fraudulent job postings are a growing global problem. Scammers post fake vacancies to harvest personal information, collect advance fees, or recruit unwitting money mules. Traditional detection relies solely on human judgment — which is slow, inconsistent, and error-prone. JOBCIPHER AI brings machine precision to this challenge.

How It Works
1
Text Input
User submits a job posting: title, description, requirements, benefits, and company profile.
2
NLP Preprocessing
Text is cleaned — HTML stripped, lowercased, non-alphabetic characters removed, whitespace normalized.
3
TF-IDF Vectorization
The cleaned text is converted into a 10,000-dimensional feature vector using unigrams and bigrams.
4
ML Classification
Logistic Regression model classifies the vector as Real or Fake, with probability confidence scores.
Machine Learning Pipeline
TF-IDF Vectorizer
  • Max Features: 10,000
  • N-gram Range: Unigrams + Bigrams (1,2)
  • TF Scaling: Sublinear
  • Stop Words: English removed
  • Vocabulary: trained on 17,880 postings
Logistic Regression
  • Class Weight: Balanced (handles imbalance)
  • Max Iterations: 1,000
  • Regularization: C = 1.0
  • Test Accuracy: 97.96%
  • Random State: 42 (reproducible)
Training Dataset
  • Source: Kaggle EMScAD Dataset
  • Total Samples: 17,880 job postings
  • Fake Jobs: ~4.84% of dataset
  • Train/Test Split: 80% / 20%
  • Stratified split to preserve class ratio
